# zihan_website
Zihan's personal website

Local dev (macOS, VS Code)
1. Open the folder in VS Code.
2. Install "Live Server" extension (Ritwick Dey).
3. Right-click `index.html` → Open with Live Server. Browser reloads on save.

Git (commit & push)
cd /Users/zihan/Documents/code/zihan_website
git add .
git commit -m "site: apply minimal professional template"
git push origin main

Publish to GitHub Pages: repo → Settings → Pages → Source: main / (root) → Save.
